# Red Team Runbook

A practical reference for authorized security assessments by PerhapsLater.

[Read the runbook](https://perhapslater.github.io/red-team-runbook/)

## Contents

- Assessment workflows and a quick command index.
- Network, service, web application, and Active Directory playbooks.
- Privilege escalation, lateral movement, persistence, file transfers, and tunneling.
- Tool references and command templates with browser-local engagement variables.

Start with the [operator workflow](docs/workflow.md) or [command index](docs/command-index.md).
Set target, subnet, listener, domain, and domain controller values in the Variables
panel to update command examples throughout the site.

Use these techniques only on systems you own or have explicit authorization to assess.
